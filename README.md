## Коротко про создание проекта 

Изначально проект для удобства и скорости создания готового продукта создавался на движке основанном на PHP "WordPress", и перенесенном в статический формат с помощью одного из его многочисленных расширений, под названием "Static Cache Wrangler".

Сайт полноценно живет и функционирует за счет корректной настройки со стороны хоста, а именно выделенной под это VPS, с локальным и функционирующим на нем реверс прокси менеджере NGINX. 

Сам WordPress и БД для него (MariaDB), следуя современным стандартам, развернуты на машине внутри Docker контейнеров, через утилиту Docker-Compose. 

На контейнер с приложением указывает наш локальный прокси, а шифрование обеспечивает бесплатный сертификат Let's Encrypt. 

Затем уже в развернутой среде был реализован полноценный функциональный сайт описывающий основные пункты из руководства к учебной практике. 

Ну дальнейшие шаги по реализации в целом понятны...
